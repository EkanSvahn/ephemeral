# Code of Conduct

Ephemeral follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to issues, pull requests, reviews and every other place where the
project is discussed.

## In short

- Be respectful, and assume the other person means well.
- Keep criticism about the work, not about the person.
- Harassment, personal attacks and discriminatory language are not accepted.
- The maintainer decides what is merged and may edit or remove contributions
  that break these rules.

## Reporting

If someone's behaviour in this project is a problem, report it privately to
the maintainer. Open the repository's **Security** tab, choose
**Report a vulnerability** and say that the report is about conduct. That form
is visible only to the maintainer, which is why it is used for this as well.

Every report is read. The reporter's identity is kept confidential. Depending
on what happened, the maintainer may remove comments, lock a thread or block an
account from the repository.
